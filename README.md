# System Resource Monitor

## Обзор
Высокопроизводительная утилита для мониторинга системных ресурсов в среде Linux. Программная архитектура базируется на принципе разделения ответственности между уровнем сбора телеметрии (Backend) и уровнем визуализации (Frontend). Для обеспечения неблокирующего сбора данных реализован фоновый поток-обработчик.

## Технические характеристики
* **Backend**: Нативный C++ с использованием асинхронного сбора метрик.
* **Concurrency**: Потокобезопасная работа с разделяемыми данными посредством `std::mutex` и `std::atomic`.
* **Communication**: HTTP-протокол реализован на базе легковесной header-only библиотеки `cpp-httplib`.
* **Frontend**: Клиентская часть на базе HTML5/JS с динамической манипуляцией DOM.

## Ключевые архитектурные решения
* **Механизм сбора телеметрии**: Прямой парсинг интерфейсов файловой системы `/proc` (в частности, `/proc/stat`, `/proc/meminfo`, `/proc/[pid]/statm`).
* **Оптимизация**: Использование фонового потока (background worker) обеспечивает $O(1)$ латентность при чтении API-эндпоинтов. Кэширование состояния системы позволяет избежать избыточного обращения к ресурсам ядра при высокой интенсивности HTTP-запросов.
* **Синхронизация**: Применение примитивов синхронизации предотвращает состояние гонки (data race) между потоком сбора метрик и потоком обработки HTTP-запросов.

## Системные требования
* **Компилятор**: Соответствие стандарту C++11 и выше (GCC/Clang).
* **Система сборки**: CMake 3.10+.
* **ОС**: Ядро Linux 3.x и выше.
